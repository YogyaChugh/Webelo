I wanted to know how a browser reads a web page, so I built that part myself.

The part of a browser that understands a web page, rebuilt from the official WHATWG spec in C++.

Download the viewerRead the docs ↗The story → Code

What it doesWebelo, in short

Follows the standard

Nodes, trees, traversal and events, built the way the WHATWG DOM Living Standard defines them.

See the tree

The viewer draws any page’s HTML as the DOM tree a browser would build from it.

C++ or Python

Include one C++ source file in your project, or use the Python bindings.
